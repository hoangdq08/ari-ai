# Backend - Nông Trí AI

Thư mục này được sử dụng để chứa mã nguồn của API Server (Backend) phục vụ cho ứng dụng Nông Trí AI.

Hiện tại, cấu trúc thư mục đang được bảo lưu (Reserved). Nhóm phát triển Backend sẽ chịu trách nhiệm khởi tạo mã nguồn, cấu hình database và xây dựng các Endpoint AI tại đây trong tương lai.
